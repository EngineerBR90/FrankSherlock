# v0.8.2

### Bug fixes

- **Face detection works again** (#12, thanks @ThiagooTavares for the detailed report): v0.8.1 shipped with mismatched ONNX components — the Rust bindings were silently upgraded by a dependency refresh to a version requiring ONNX Runtime 1.27+, while the app bundles 1.23. Face detection failed at initialization on every platform before processing a single image. The bindings are now pinned to the version matching the bundled runtime, and a new regression test performs the runtime-version handshake in CI on Linux, macOS, and Windows so this mismatch can never ship again.

- **Face detection failures are no longer silent**: any error in the face detection worker (model download failure, runtime initialization failure, model load failure) now appears as an error message in the UI instead of only being written to the log file, and a failed run no longer blocks retrying.

### Maintenance

- Updated rustls, clearing security advisory RUSTSEC-2026-0285.

### Test suite

- 345 Rust tests, 336 frontend tests.
